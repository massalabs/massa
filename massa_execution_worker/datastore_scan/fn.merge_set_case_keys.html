Expand description

Builds the bounded result for a Set reset by streaming the absolute datastore in key order and overlaying the newer-layer updates, stopping as soon as count surviving keys are collected. A naive truncation of the absolute range would be wrong: a newer update may delete one of the first count keys, which must then be replaced by the next key.

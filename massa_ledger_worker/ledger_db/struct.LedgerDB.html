fn update_entry( &self, addr: &Address, entry_update: LedgerEntryUpdate, batch: &mut DBBatch, )

Update the ledger entry of a given address.

If the address has no canonical entry yet (no VERSION marker), a default entry is materialized first via Self::put_entry, matching the contract documented on Self::apply_changes_to_batch and the LedgerChanges Vacant helpers (F84).

§Arguments

3//! MASSA Cipher crate
4//!
5//! `massa-cipher` uses AES-GCM
6//!
7//! AES-GCM is a state-of-the-art high-performance Authenticated Encryption with Associated Data (AEAD)
8//! that provides confidentiality and authenticity.
9//!
10//! To hash the password before using it as a cipher key, we use the `PBKDF2` key derivation function
11//! as specified in [RFC 2898](https://datatracker.ietf.org/doc/html/rfc2898).
12//!
13//! The AES-GCM crate we use has received one security audit by NCC Group, with no significant findings.

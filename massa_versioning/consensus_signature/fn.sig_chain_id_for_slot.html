Expand description

Returns the sig_chain_id to use for signing / verifying an endorsement or block header whose slot timestamp is slot_ts on the local chain identified by chain_id.

Returns Some(chain_id) once the Execution component is active at version >= MIP_0002_EXECUTION_VERSION for that slot, None otherwise (legacy layout).

Every signing / verification / denunciation-reconstruction site must call this with the message’s own slot timestamp so all nodes switch layouts simultaneously at the activation slot (no partition).
